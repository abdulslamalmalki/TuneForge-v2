## Approved identities

- **DRAM VPP Voltage** - 8 mappings across 3 vendors: asrock, asus, msi. ASRock, ASUS, and MSI use the exact label and identify the same DRAM-side or PMIC VPP supply.
- **Native ASPM** - 6 mappings across 3 vendors: asus, gigabyte, msi. ASUS, MSI, and GIGABYTE use the exact label and distinguish OS-controlled ASPM from BIOS-controlled ASPM.
- **PCIe Tunneling over USB4** - 5 mappings across 3 vendors: asus, gigabyte, msi. ASUS, MSI, and GIGABYTE use the same label and explicitly describe enabling or disabling PCIe tunneling over USB4.
- **SATA Mode** - 4 mappings across 3 vendors: asus, gigabyte, msi. GIGABYTE, MSI, and ASUS use the exact label and document the same chipset SATA-controller mode selection.
- **VDDP Voltage** - 4 mappings across 3 vendors: asrock, asus, msi. ASRock, MSI, and ASUS use the exact label and describe the same AMD VDDP voltage target or control.
- **Data Scramble** - 3 mappings across 3 vendors: asrock, asus, msi. ASRock, MSI, and ASUS use the exact label with matching Auto, Disabled, and Enabled behavior in AMD memory-controller menus.
- **DRAM ECC** - 3 mappings across 3 vendors: asrock, asus, msi. ASRock, MSI, and ASUS use the label ECC in equivalent AMD memory-controller contexts and describe the same DRAM ECC control.
- **Legacy Game Compatibility Mode** - 3 mappings across 3 vendors: asus, gigabyte, msi. MSI, GIGABYTE, and ASUS use the exact label and identify the same older-game compatibility function.
- **SMT Control** - 3 mappings across 3 vendors: asrock, asus, msi. ASRock, MSI, and ASUS use the exact label and describe disabling or automatically enabling symmetric multithreading.
- **TDC Control** - 3 mappings across 3 vendors: asrock, asus, msi. ASRock, MSI, and ASUS use the exact label and consistently describe BIOS/default versus manual TDC-limit control.
- **TDP Control** - 3 mappings across 3 vendors: asrock, asus, msi. ASRock, MSI, and ASUS use the exact label and consistently describe BIOS/default versus manual TDP-limit control.
- **Thermal Control** - 3 mappings across 3 vendors: asrock, asus, msi. ASRock, MSI, and ASUS use the exact label and consistently describe BIOS/default versus manual Tctl maximum control.
- **UMA Frame Buffer Size** - 3 mappings across 3 vendors: asus, gigabyte, msi. GIGABYTE, MSI, and ASUS use the exact label and describe the same system-memory allocation for integrated graphics.
