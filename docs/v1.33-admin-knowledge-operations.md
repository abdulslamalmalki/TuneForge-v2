# Admin knowledge operations

Milestone 13 improves the existing curator workspace without creating a second
set of review workflows or duplicating knowledge state.

## Dashboard coverage

`/admin` now computes six read-only reviewed-data coverage projections:

- approved Source Settings with a canonical mapping;
- active Canonical Settings with at least one approved Guidance Claim;
- approved Source Settings directly bound to an approved claim;
- approved Guidance Claims with an explicit reviewed hardware target;
- approved Guidance Claims with an explicit reviewed BIOS-version boundary;
- active Canonical Settings with an approved Recommendation Claim.

Each card shows the exact numerator, denominator, percentage, definition, and a
link to the existing responsible workflow. Zero means no reviewed records meet
that criterion; it is never replaced with candidate or inferred coverage.

The footprint summary separately reports vendors, normalized platforms, exact
chipsets represented by approved settings, and open scope-aware claim conflicts.

## Queue consolidation

The work list continues to link to existing source-of-truth queues. Two missing
operational projections were added:

- approved Source Settings still awaiting a verified canonical mapping;
- active Canonical Settings without approved factual guidance.

All active queues appear first. Zero-count queues remain available in one
collapsed “clear queues” section, reducing dashboard noise without hiding any
workflow. Research promotion, candidates, claims, recommendations, conflicts,
mapping suggestions, extraction failures, and refusal demand still use their
existing domain pages and review rules.

The shared admin navigation now exposes the existing Knowledge Conflicts queue,
which was previously reachable from the dashboard but absent from the sidebar.

## Production measurement

Against the current reviewed database when this milestone was implemented, the
dashboard projection completed in approximately 0.08 seconds and reported:

```text
Canonical mapping       1,206 / 4,018  (30.0%)
Verified guidance          14 /   331  (4.2%)
Direct source evidence      0 / 4,018  (0.0%)
Hardware-scoped claims      0 /    17  (0.0%)
BIOS-scoped claims          0 /    17  (0.0%)
Safe recommendations        0 /   331  (0.0%)
Vendors                     4
Platforms                   1
Exact chipsets              4
Open claim conflicts        0
```

These figures are deliberately strict. For example, a general Evidence Source
supporting a canonical claim does not count as a Source Setting directly bound
to that claim, and a source-scoped claim does not count as explicitly
hardware-scoped.

No migration, knowledge mutation, approval shortcut, or new review-state table
was introduced.
