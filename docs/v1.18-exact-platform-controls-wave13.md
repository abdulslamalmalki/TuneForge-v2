## Approved identities

- **Realtime Memory Timing** - 5 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name in advanced memory controls; ASUS identifies changes after MRC_DONE and GIGABYTE describes fine-tuning after the BIOS stage.
- **Dynamic Memory Boost** - 4 mappings across 2 vendors: asus, msi. ASUS and MSI use the exact normalized name in memory-frequency controls; ASUS documents automatic SPD/XMP switching and MSI identifies the same memory boost control.
- **Realtime Memory Frequency** - 4 mappings across 2 vendors: asus, msi. ASUS and MSI use the exact normalized name beside Dynamic Memory Boost; ASUS documents manual runtime SPD/XMP switching and MSI identifies the same realtime frequency control.
- **Next Boot after AC Power Loss** - 4 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name under Boot and provide matching Normal Boot and Fast Boot behavior after AC power loss.
- **CFG Lock** - 3 mappings across 2 vendors: gigabyte, msi. MSI and GIGABYTE use the exact normalized name; MSI identifies MSR 0xE2 bit 15 and GIGABYTE identifies the MSR 0xE2 function.
- **DTBT Go2Sx Command** - 3 mappings across 2 vendors: asus, msi. ASUS and MSI use the exact normalized name in discrete Thunderbolt configuration and describe the same command before/during entry to Sx states.
- **Enhanced TVB** - 3 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name in TVB/CPU controls; GIGABYTE identifies Enhanced Thermal Velocity Boost and ASUS limits the option to supported SKUs.
- **Internal Graphics** - 3 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name in graphics/IO configuration and both describe enabling or disabling internal/onboard graphics.
- **Discrete Thunderbolt(TM) Support** - 3 mappings across 2 vendors: asus, msi. ASUS and MSI use the exact normalized name in Thunderbolt configuration and both describe enabling or disabling discrete Thunderbolt device support.
- **FCH Spread Spectrum** - 2 mappings across 2 vendors: asrock, msi. ASRock and MSI use the exact normalized name under AMD platform controls; both enable or disable FCH spread spectrum, and MSI documents EMI and base-clock-overclocking effects.
