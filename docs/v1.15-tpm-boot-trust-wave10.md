## Approved identities

- **TPM Device Selection** - 3 mappings across 2 vendors: asus, msi. Two ASUS manuals and one MSI manual use the exact normalized name and consistently describe mutually exclusive firmware-TPM and discrete/hardware-TPM selection.
- **SHA-1 PCR Bank** - 2 mappings across 2 vendors: asus, msi. ASUS and MSI use the exact normalized name in Trusted Computing and both official descriptions define the same enable/disable control for the SHA-1 PCR bank.
- **Enroll Efi Image** - 2 mappings across 2 vendors: asrock, msi. ASRock and MSI use the exact normalized name under Secure Boot Key Management and both official descriptions enroll an image SHA-256 value into the authorized signature database so the image can run in Secure Boot mode.
