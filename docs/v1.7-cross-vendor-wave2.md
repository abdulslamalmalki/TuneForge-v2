- New canonical settings: 23

All mapping decisions use visually reviewed official manual pages as primary evidence. TCG, PCI-SIG, and UEFI specifications are supporting primary evidence only; no community source is used as the sole basis for approval.

## Notable exclusions

- **PSS Support** - ASUS record 6111 omits the _PSS ACPI object documented by the existing identity; it remains unmapped.
- **PPT Control** - The same label is used both for Package Power Tracking limits and for a DDR training-pattern control; exact naming is unsafe.
- **Integrated Graphics** - Official descriptions disagree between controller enablement and UMA memory-allocation behavior.
- **Global C-state Control** - One official source describes general CPU C-states while others specifically describe I/O-generated and Data Fabric C-states.
- **Clear Secure Boot Keys** - The previously reviewed ASRock hierarchy remains ambiguous; the proposal stays rejected.

The machine-readable report contains every source decision and the complete pending backlog: `data/reports/v1.7-cross-vendor-wave2.json`.
