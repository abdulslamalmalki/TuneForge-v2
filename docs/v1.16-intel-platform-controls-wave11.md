- **DMI ASPM** - 4 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name and describe ASPM support or mode selection for the DMI link; GIGABYTE explicitly identifies both CPU and chipset sides.
- **DVMT Pre-Allocated** - 4 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name in graphics configuration; ASUS identifies DVMT fixed graphics memory and GIGABYTE describes onboard graphics memory size.
- **Intel(R) Speed Shift Technology** - 4 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name; ASUS documents hardware-controlled P-states and GIGABYTE documents faster processor frequency ramping and responsiveness.
- **PEG ASPM** - 4 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE names normalize exactly after punctuation handling and both official descriptions control ASPM for the CPU PEG connection.
- **RC6(Render Standby)** - 4 mappings across 2 vendors: asus, gigabyte. ASUS and GIGABYTE use the exact normalized name in graphics or platform-power configuration; both official descriptions control onboard/integrated graphics render standby for power reduction.
- **TVB Voltage Optimizations** - 4 mappings across 2 vendors: asus, msi. ASUS and MSI use the exact normalized name and both official descriptions control thermally based voltage optimization for processors implementing TVB.
